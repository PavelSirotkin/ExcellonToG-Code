# Excellon to G-Code Converter v3.0

Генератор G-code из файлов сверловки и фрезеровки печатных плат с интерактивной визуализацией и проигрывателем G-code.

![Python](https://img.shields.io/badge/Python-3.8+-blue)
![License](https://img.shields.io/badge/License-Free-green)

## Возможности

### Поддержка форматов
- **Excellon** файлы (.txt, .drl) — круглые отверстия
- **SlotHoles** — овальные отверстия (слоты)
- Автоматическое определение формата координат (3.2, 3.3, 4.2, 4.3, 4.4) из заголовка файла
- Ручной выбор формата при необходимости

### Три режима генерации G-code
- **Сверловка** — только круглые отверстия
- **Фрезеровка слотов** — только овальные отверстия
- **Комбинированный** — полная обработка платы

### Визуализация
- Двухслойное отображение отверстий и слотов с цветовой кодировкой по инструментам
- Реалистичное отображение слотов (полноценные овалы с учётом диаметра инструмента)
- Интерактивный зум (колесо мыши) и панорамирование (перетаскивание)
- Адаптивная сетка с автоматическим масштабированием
- Линейки с рассчитанными делениями
- Интерактивная легенда — наведение подсвечивает инструмент, клик изолирует

### Проигрыватель G-code
- Анимация сгенерированного G-code в реальном времени
- Управление: Play / Pause / Stop
- Регулируемая скорость воспроизведения (1x–20x)
- Слайдер для навигации по кадрам
- Индикатор текущей позиции и команды

### Статистика обработки
- Габариты платы (диапазоны X, Y)
- Количество отверстий и слотов по инструментам
- Суммарные длины траекторий (быстрые перемещения XY, подача Z, фрезеровка)
- Расчётное время обработки (минуты:секунды)

### Параметры G-code
| Параметр | Описание |
|----------|----------|
| Z safe | Безопасная высота |
| Z drill | Глубина сверления |
| Feed (рабочая) | Подача сверления мм/мин |
| Feed (быстрая) | Скорость холостого хода мм/мин |
| Feed (фреза) | Подача фрезеровки мм/мин |
| Parking | Парковка в (0, 0, Z_park) после каждого инструмента |

### Оптимизация
- Алгоритм ближайшего соседа для оптимизации траектории обхода отверстий и слотов
- Cohen–Sutherland line clipping для производительного отображения
- Отсечение элементов за пределами viewport

## Установка и запуск

### Требования
- Python 3.8+
- tkinter (входит в стандартную поставку Python)

### Запуск
```bash
python ExcellonToG-Code_V_3.0.py
```

## Использование

1. Нажмите **«Открыть Excellon»** для загрузки файла сверловки
2. При необходимости загрузите файл слотов кнопкой **«Открыть SlotHoles»**
3. Формат координат определится автоматически (или выберите вручную)
4. Настройте параметры G-code в правой панели
5. Нажмите **«Генерировать G-code»** — выберите режим генерации
6. Используйте **«📊 Статистика»** для просмотра информации об обработке
7. Используйте **«🎬 Визуализация G-code»** для проигрывания сгенерированного кода
