# ExcellonToG-Code

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![Tests](https://img.shields.io/badge/Tests-139%20passing-brightgreen.svg)](tests/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**Конвертация Excellon-файлов (сверление PCB) в G-code для ЧПУ-станков.**

Приложение с графическим интерфейсом для просмотра, оптимизации маршрута и генерации G-code из файлов сверления формата Excellon, включая поддержку слотов (овальных отверстий) и 2.5D-визуализацию процесса обработки.

## ⚡ Быстрый старт


## 🎯 Возможности

### Работа с файлами
- **Парсинг Excellon-файлов** — круглые отверстия (Round Holes)
- **Парсинг SlotHoles-файлов** — овальные отверстия (слоты)
- **Автоопределение формата координат** (2.4, 3.3, 4.2)
- **Предупреждение о конфликте форматов** при загрузке файлов с разными настройками

### Оптимизация маршрута
- **Nearest Neighbor + 2-opt** — алгоритмы оптимизации порядка обработки отверстий
- Минимизация холостых перемещений инструмента
- Отдельная оптимизация для слотов (учёт точек входа и выхода)

### Генерация G-code
| Функция | Описание |
|---------|----------|
| ⚙ G-код сверления | Только круглые отверстия |
| ⚙ G-код фрезеровки | Только слоты |
| ⚙ Объединённый G-code | Сверление + фрезеровка в одном файле |
| M03 S{RPM} | Скорость шпинделя для каждого инструмента (режим «Про») |

### Режимы работы

#### 🔧 Простой
- Все параметры задаются глобально (подача, безопасная Z, глубина)
- Работает идентично версии 3.2
- Идеально для разовых задач

#### ⚙ Про
- **База инструментов** — параметры (RPM, подача, скорость подъёма) для каждого диаметра
- **Автоматический подбор** параметров из базы при генерации
- **Предупреждение** об отсутствующих инструментах
- **Редактор базы** — добавление, редактирование, импорт/экспорт JSON

### Визуализация
- **2.5D кабинетная проекция** — трёхмерный вид процесса обработки
- **Плеер** — пошаговый просмотр с регулировкой скорости
- **Интерактивная легенда** — фильтрация по инструментам, подсветка при наведении
- **Всплывающие подсказки** — координаты и параметры при клике ПКМ

### Навигация
| Действие | Управление |
|----------|------------|
| Масштаб | Колесо мыши |
| Перемещение | Зажатая ЛКМ |
| Автозум | Двойной клик ЛКМ |
| Подсказка | ПКМ на элементе |

## 📄 Форматы файлов

### Входные
| Формат | Описание |
|--------|----------|
| `*.TXT`, `*.DRL` | Excellon-файлы (круглые отверстия) |
| `*.TXT`, `*.DRL` | SlotHoles-файлы (овальные отверстия) |

### Выходные
| Формат | Описание |
|--------|----------|
| `*.TAP`, `*.gcode`, `*.nc`, `*.ngc` | G-code для ЧПУ |
| `*.json` | База инструментов (`tool_base.json`) |
| `*.json` | Параметры G-code (`gcode_params.json`) |
