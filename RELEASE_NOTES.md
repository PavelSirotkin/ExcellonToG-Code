## 🆕 Новый функционал

### Финишная обрезка платы (Board Outline Milling)

- **Парсер Gerber-файлов (RS-274X)** — импорт контура платы (edge-cuts) из Gerber:
  - Поддержка линейных сегментов (G01)
  - Поддержка дуг (G02/G03) с центрными Смещениями (I/J)
  - Автоматическое определение единиц измерения (мм/дюймы)
  - Поддержка Gerber-регионов (G36/G37) для замыкания контура
  - Проверка замкнутости контура

- **Генерация G-code для обрезки**:
  - **Offset контура** — автоматическое смещение на радиус фрезы
  - **Многопроходная фрезеровка** — задание глубины за проход (`depth_per_pass`)
  - **Tabs (держательные перемычки)**:
    - Автоматическая вставка `n_tabs` перемычек по длине контура
    - Настройка ширины (`tab_width`) и высоты (`tab_height`)
    - Правильная обработка переходов над tab (остановка шпинделя не требуется)
    - Поддержка CW и CCW направления обхода
  - **Отдельные параметры** для контура:
    - `tool_diameter` — Диаметр фрезы для обрезки
    - `mill_feed` — Подача при резе XY (overrides глобальной)
    - `plunge_feed` — Подача при погружении Z
    - `spindle_speed` — Частота вращения шпинделя (опционально)

### Геометрические операции с полигонами

**Новый модуль `polygon_ops.py`:**

| Функция | Описание |
|---------|----------|
| `bounding_box()` | Вычисление bounding box контура |
| `polygon_signed_area()` | Ориентированная площадь многоугольника |
| `is_ccw()` / `normalize_to_ccw()` | Проверка/нормализация ориентации (CCW) |
| `point_in_polygon()` | Ray casting алгоритм проверки точки внутри полигона |
| `flatten()` | Преобразование дуг в хорды с точностью `tol_mm` |
| `offset_segments()` | Смещение контура наружу/внутрь с обработкой углов |
| `insert_tabs()` | Вставка перемычек с расчётом позиций по длине |
| `compute_total_length()` | Вычисление общей длины контура (линии + дуги) |
| `point_at_length()` | Поиск точки на заданном расстоянии от начала |

### Улучшения парсера Gerber

- **Поддержка режимов координат**: абсолютный (`G90`), относительный (`G91`)
- **Парсинг формата координат** из заголовка `%FS...%`
- **Конвертация дюймов в мм** автоматически
- **Обработка D-кодов**: D01 (резка), D02 (перемещение)
- **Игнорирование мёртвого кода** (комментарии, заголовки)
- **Векторная обработка** — без GUI зависимостей

## 🐛 Исправления ошибок

### Критические (исправлено в v4.5)
- ✗ Пустые координаты подставляли 0 → ✓ требуются обе (X и Y)
- ✗ Все перемещения использовали параметры инструмента → ✓ XY всегда global rapid_rate
- ✗ Проверка заголовка Excellon только 3 строки → ✓ 10 строк
- ✗ Файлы JSON не загружались из .exe → ✓ `sys.frozen` проверка

### Предупреждения (исправлено в v4.5)
- ✗ `mill_feed` не валидировался → ✓ добавлена валидация
- ✗ Нет проверки видимых инструментов → ✓ добавлена при генерации
- ✗ Нет проверки пустых данных → ✓ добавлена после парсинга
- ✗ Viz exit привязывал другие функции → ✓ сохраняет оригинальные биндинги
- ✗ Редундантный `% n` в TSP → ✓ убран
