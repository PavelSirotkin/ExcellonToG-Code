## 🆕 Новый функционал

### Режимы работы «Простой» / «Про»
- **Кнопка-переключатель** режимов в правой панели
- **«Простой» режим** — работает как раньше (v3.2), все параметры задаются глобально
- **«Про» режим** — добавлена база инструментов с параметрами, генерация G-code с учётом параметров каждого инструмента

### База инструментов (`tool_base.json`)
- Два типа инструментов: **Сверла** и **Фрезы**
- Ключ поиска — диаметр инструмента
- **Сверла:** частота вращения (об/мин), скорость погружения (мм/мин), скорость подъёма (мм/мин), заметки
- **Фрезы:** частота вращения (об/мин), скорость реза XY (мм/мин), скорость погружения Z (мм/мин), ширина перекрытия (%), заметки
- **Автосохранение** — каждое изменение автоматически сохраняется
- **Редактор базы** — окно с двумя вкладками, CRUD-операциями, импорт/экспорт JSON
- **Автозагрузка** при старте, создаётся автоматически если отсутствует

### Параметры G-code (`gcode_params.json`)
- Параметры сохраняются в отдельный JSON-файл
- Автозагрузка при старте, создание с параметрами по умолчанию при отсутствии
- Автосохранение перед каждой генерацией

### Улучшенная генерация G-code
- **`M03 S{RPM}`** — в режиме «Про» генерируется скорость шпинделя из базы
- **Вертикальные перемещения Z** используют параметры инструмента из базы
- **Горизонтальные перемещения XY** всегда используют глобальный `rapid_rate`
- **Предупреждение о недостающих инструментах** — если инструмент не найден в базе, выводится диалог с перечнем
- **Поддержка multi-pass слотов** — заложена архитектура для многопроходной фрезеровки

### Предупреждение о конфликте форматов
- При загрузке второго файла проверяется формат координат
- Если форматы отличаются — выводится предупреждение, используется формат первого файла

### Ключевые улучшения
- **core не зависит от tkinter** — чистая бизнес-логика
- **Нет кольцевых зависимостей** — однонаправленный граф: `main → ui → core`
- **Удалены неиспользуемые импорты** — 5 файлов очищены
- **Удалён мёртвый код** — `viz_project()`, `SIMULATOR_URL`
- **Устранены дубликаты** — `colors`/`slot_colors` вынесены в config
- **Исправлена логика координат** — требуются обе координаты (X и Y)
- **Исправлена генерация G-code** — XY всегда использует `rapid_rate`

## 🐛 Исправления ошибок

### Критические (исправлено в v4.0)
- ✗ tkinter импортировался в core → ✓ вынесен в ui слой
- ✗ Пустые координаты подставляли 0 → ✓ требуются обе (X и Y)
- ✗ Кнопка «База инструментов» не появлялась → ✓ исправлен pack/pack_forget
- ✗ Все перемещения использовали параметры инструмента → ✓ XY всегда global rapid_rate
- ✗ Проверка заголовка Excellon только 3 строки → ✓ 10 строк

### Предупреждения (исправлено в v4.0)
- ✗ `mill_feed` не валидировался → ✓ добавлена валидация
- ✗ Нет проверки видимых инструментов → ✓ добавлена при генерации
- ✗ Нет проверки пустых данных → ✓ добавлена после парсинга
- ✗ Viz exit привязывал другие функции → ✓ сохраняет оригинальные биндинги
- ✗ Редундантный `% n` в TSP → ✓ убран
