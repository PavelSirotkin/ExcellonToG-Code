# Система справки ExcellonToG-Code

## Обзор

Улучшенная справочная система с двумя компонентами:

### 1. Встроенное окно справки (`ui/help_window.py`)

**Возможности:**
- Древовидная навигация по 12 категориям и 50+ разделам
- Форматированное содержимое (заголовки, списки, подсказки, предупреждения)
- История навигации (кнопки Назад/Вперёд)
- Поиск по всему содержимому справки
- Адаптивный интерфейс с изменяемым размером

**Вызов:**
- Кнопка "❓ Справка" в интерфейсе
- Горячая клавиша **F1**

**Структура разделов:**
1. Начало работы (Быстрый старт)
2. Форматы файлов (Excellon, SlotHoles, Gerber)
3. Параметры G-code (все 6 параметров)
4. Режимы работы (Простой/Про, База инструментов)
5. Обрезка по контуру (параметры, перемычки)
6. Визуализация (плеер, легенда, фильтры)
7. Управление (навигация, масштаб, hotkeys)
8. Генерация G-code (4 типа)
9. Оптимизация (TSP, Nearest Neighbor, 2-opt)
10. Решение проблем (типичные ошибки)
11. Советы (материалы, двусторонние платы)
12. О программе (версия, автор, требования)

### 2. Контекстные tooltips (`ui/enhanced_tooltip.py`)

**Возможности:**
- Задержка 500мс перед показом (не мешают работе)
- Форматированный текст на жёлтом фоне
- Подсказка о клавише F1 для полной справки
- Автоматическое скрытие при клике или уходе мыши

**Покрытие:**
- Все кнопки загрузки файлов
- Все поля параметров G-code
- Кнопки генерации
- Параметры контура
- Элементы управления

## Файлы

### Новые файлы:
- `docs/__init__.py` - инициализация модуля документации
- `docs/help_content.py` - структурированное содержимое справки (словарь HELP_SECTIONS)
- `ui/help_window.py` - класс HelpWindow с навигацией и рендерингом
- `ui/enhanced_tooltip.py` - класс EnhancedTooltip и словарь TOOLTIPS

### Изменённые файлы:
- `ui/dialogs.py` - функция open_help() теперь вызывает новое окно справки
- `ui/app.py` - добавлен импорт tooltips, привязка к виджетам, горячая клавиша F1

## Использование

### Для пользователей:
1. Нажмите F1 в любой момент для вызова справки
2. Наведите мышь на элемент интерфейса для быстрой подсказки
3. Используйте поиск в окне справки для быстрого нахождения информации

### Для разработчиков:

**Добавление нового раздела справки:**
```python
# В docs/help_content.py
HELP_SECTIONS["new_section"] = {
    "title": "🔧 Новый раздел",
    "content": [
        {"type": "title", "text": "Заголовок"},
        {"type": "paragraph", "text": "Текст параграфа"},
        {"type": "h2", "text": "Подзаголовок"},
        {"type": "bullet", "text": "Пункт списка"},
        {"type": "tip", "text": "Полезный совет"},
        {"type": "warning", "text": "Предупреждение"},
        {"type": "code", "text": "G0 X10 Y20"},
    ]
}
```

**Добавление tooltip к виджету:**
```python
# В ui/app.py
from ui.enhanced_tooltip import EnhancedTooltip, TOOLTIPS

# Добавить в TOOLTIPS (ui/enhanced_tooltip.py)
TOOLTIPS["my_button"] = "Описание кнопки\nМожет быть многострочным"

# Привязать к виджету
btn = tk.Button(parent, text="Моя кнопка", command=my_func)
EnhancedTooltip(btn, TOOLTIPS["my_button"])
```

## Типы блоков содержимого

- `title` - главный заголовок (18pt, синий)
- `h2` - подзаголовок 2 уровня (14pt, синий)
- `h3` - подзаголовок 3 уровня (12pt, синий)
- `paragraph` - обычный текст
- `bullet` - элемент маркированного списка
- `code` - код/команды (моноширинный шрифт, серый фон)
- `tip` - полезный совет (💡, голубой фон)
- `warning` - предупреждение (⚠️, жёлтый фон)

## Горячие клавиши

- **F1** - открыть справку (работает из любого места приложения)
