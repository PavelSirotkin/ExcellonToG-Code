# 📊 Улучшенное окно статистики

## Обзор

Новое окно статистики предоставляет визуально привлекательное и информативное представление данных проекта с улучшенной структурой и дополнительными метриками.

## Основные улучшения

### 1. Визуальное представление
- **Современный дизайн** с цветовым кодированием
- **Структурированные секции** с рамками и заголовками
- **Цветовые акценты** для разных типов данных
- **Иконки** для лучшей читаемости

### 2. Дополнительная информация

#### 📐 Размеры платы
- Диапазоны координат X и Y
- Ширина и высота платы
- **Площадь платы** (см²) - новая метрика

#### 🔧 Инструменты (раздельное отображение)
- **Три независимых раздела**:
  - **Отверстий** — количество отверстий и свёрл
  - **Слотов** — количество движений слотами и фрез
  - **Обрезка** — наличие контура и инструментов для него
- Сводка для каждого раздела
- Таблица инструментов с чередующимися цветами строк
- Четкое разделение на сверла, фрезы для слотов и контур

#### 🛤️ Путь инструмента
- Холостой ход (XY) с конвертацией в метры
- Рабочий ход (Z) с конвертацией в метры
- Фрезеровка слотов (если есть)
- **Фрезеровка контура** (если есть)
- **Фрезеровка (всего)** — сумма фрезеровки слотов и контура
- **Общий путь** — новая метрика

#### ⏱️ Время обработки
- **Крупное отображение** общего времени
- **Визуальные прогресс-бары** для каждого типа операции
- Процентное распределение времени
- Детализация по типам: холостой ход, сверление, фрезеровка (слоты + контур)

### 3. Новые функции

#### 📋 Копирование в буфер обмена
- Кнопка "Копировать" для экспорта данных
- Форматированный текстовый отчёт
- Удобно для документации и отчётов

#### Улучшенная навигация
- Модальное окно с фиксированным размером
- Центрирование относительно главного окна
- Кнопка закрытия с визуальным стилем

### 4. Поддержка Gerber-контуров

#### Формат Gerber parser
- Поддержка **линий**: `{'type': 'line', 'p1': (x1, y1), 'p2': (x2, y2)}`
- Поддержка **дуг**: `{'type': 'arc', 'start': (x1, y1), 'end': (x2, y2), ...}`
- Корректный расчёт пути контура с учётом быстрых переходов между сегментами
- Контур отображается как один инструмент `Tконтур`

## Цветовая схема

- **#3498DB** (синий) — холостой ход, размеры X/Y, обрезка
- **#27AE60** (зелёный) — отверстия, рабочий ход Z, сверление
- **#E74C3C** (красный) — слоты, фрезеровка
- **#9B59B6** (фиолетовый) — площадь, общий путь
- **#2C3E50** (тёмно-синий) — заголовки, общее время

## Использование

1. Загрузите файлы Excellon (отверстия и/или слоты)
2. Нажмите кнопку **"📊 Статистика"** в правой панели
3. Просмотрите детальную информацию в новом окне
4. При необходимости нажмите **"📋 Копировать"** для экспорта данных
5. Закройте окно кнопкой **"✖ Закрыть"**

## Технические детали

### Файлы
- `ui/statistics_window.py` - новый модуль с классом StatisticsWindow
- `ui/app.py` - обновлён вызов статистики

### Зависимости
- tkinter (стандартная библиотека)
- core.config - для доступа к данным проекта

### Расчёты
- Площадь платы: `(max_x - min_x) * (max_y - min_y) / 100` см²
- Время: учитывает скорости `rapid_rate`, `feed_rate`, `mill_feed`
- Путь: суммирует все перемещения инструмента
- Поддержка Gerber parser: формат `p1/p2` для линий и `start/end` для дуг

### Ключевые переменные
- `total_holes` — общее количество отверстий
- `drill_tools_count` — количество свёрл
- `total_slots` — количество движений слотами (1 на инструмент)
- `slot_tools_count` — количество фрез для слотов
- `total_board_outline` — 1 если есть контур, 0 если нет
- `outline_tools_count` — количество инструментов для контура (всегда 1)
- `slot_feed_dist` — длина фрезеровки слотов
- `outline_feed_dist` — длина фрезеровки контура
- `total_milling_dist` — сумма `slot_feed_dist` + `outline_feed_dist`
