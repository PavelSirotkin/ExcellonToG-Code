# ExcellonToG-Code v5.3

## Новые возможности

### 📐 Поддержка формата Exp (явная десятичная точка)

Добавлена полная поддержка Excellon-файлов с явной десятичной точкой в координатах (формат `Exp`). Теперь программа корректно обрабатывает файлы KiCAD/Pcbnew с координатами вида `X1.0Y59.0`.

**Что изменилось:**
- Автоматическое определение формата `Exp` при сканировании тела файла
- Прямое чтение координат через `float()` при наличии десятичной точки
- Добавлено значение `"Exp"` в UI combobox формата координат
- Расширены регулярные выражения для захвата десятичных координат
- Валидатор принимает `"Exp"` как корректное значение (case-sensitive)

**Совместимость:** Изменения полностью обратно совместимы. Файлы с целочисленными координатами и форматами `2.4`/`3.3`/`4.2` продолжают работать как раньше.

**Тесты:** Добавлено 7 новых тестов в `TestExplicitDecimalFormat`. Общее покрытие: **378 passed**.

### 🌐 Локализация легенды

Исправлена локализация в строке легенды для инструмента обрезки по контуру. В русской версии англоязычное слово `tabs` заменено на сокращение `пер.` (от «перемычки»).

**Файл:** `i18n/strings_ru.json` (ключ `legend.row.outline`)
